How a build runs

  1. ScoutReads the brief, the codebase and the people. Writes down what done looks like before anything gets built.
  2. BuildSmall, working slices. Every slice runs in a real browser before it counts.
  3. CritiqueEach slice gets reviewed against the brief. Anything that doesn't serve it gets cut.
  4. ShipDeployed, measured, handed over with notes the next person can actually use.
